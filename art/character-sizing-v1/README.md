# Character size reference

`roster-before-after.jpg` shows the measured original standing sizes and the shared campaign sizes: 160px for the main roster and 105px for Z-God. `measurements.json` records the original scale, source silhouette height and new reference scale.

These are calibration previews assembled from existing art, not replacement character designs. Runtime uses the scales from `gameplay/characterSizes.generated.json`. See `docs/character-sizing-v1.md` for the integration policy and rebuild instructions.
