# Power-up icon atlas v2

Generated against the pickup inventory in main commit `52f386d` using the built-in image generation tool. This is a new, non-destructive artwork candidate; existing runtime assets are not replaced.

The atlas uses four columns and four rows in row-major order:

1. Ink Blaster
2. Flame Sword
3. Frost Gauntlet
4. Ember Boots
5. Storm Halo
6. Rapid Fire
7. Fan Shots
8. Heat Seekers (ground)
9. Ink Shield
10. Gravity Core
11. Health Heart
12. Rooftop Rush Star
13. Flight Spread Shot
14. Plasma Lance
15. Flight Homing Missiles
16. Hull Repair

Companion unlocks retain their established character designs. Fists are a default state, not a pickup; coins are currency.

Art direction: bold irregular black contours, saturated colored-pencil and crayon shading, hand-drawn notebook style, transparent background, equal cells with generous padding, readable at mobile HUD scale. No labels or background plaques.

Review and slice the approved atlas before replacing gameplay icons; preserve pickup collision sizes and gameplay behavior.
