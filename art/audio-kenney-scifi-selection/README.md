# Kenney sci-fi sound shortlist

These 24 original Ogg files were downloaded from [Kenney’s Sci-fi Sounds 1.0](https://kenney.nl/assets/sci-fi-sounds) on November 13, 2026. Kenney released the pack under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). See the included license for the original credit.

The originals are kept here for auditioning and re-editing. The game uses five edited WAVs. Their source filenames, trim points, and gameplay triggers are documented in [the game’s audio source notes](../../public/audio/sfx-kenney/SOURCES.md).
