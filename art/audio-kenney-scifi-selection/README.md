# Kenney sci-fi sound candidates

Sound effects by **Kenney** — [Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds), version 1.0. Licensed [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/); the original license is in `License.txt`. Credit is appreciated by the creator and is included here at the project's request.

Downloaded from the creator on November 13, 2026. These 24 original OGG files are a shortlist for listening, not yet integrated into the game. Selection is based on the pack's file names and the campaign's needs; their suitability, volume, length and loop points still need an audible review.

| Files | Candidate use |
| --- | --- |
| `computerNoise_000`–`003` | Void Pursuer lock-on, boss warning, or Dread Planet machinery. |
| `forceField_000`–`004` | Void Regent phase change, shield or energy-field event. |
| `spaceEngineSmall_000`–`004` | Starbreak craft engine, launch, or movement accent. |
| `spaceEngineLow_000`–`004` | Void Pursuer approach or Dread Planet machinery ambience. |
| `thrusterFire_000`–`004` | Ship thrust, launches, or a pressure-vent hazard. |

The existing game has laser, missile, explosion and shield cues, so these candidates should be compared against the current mix before any replacement. Some source sounds may require trimming, fading, leveling, or a new event hook. No modifications have been made to the source files.
