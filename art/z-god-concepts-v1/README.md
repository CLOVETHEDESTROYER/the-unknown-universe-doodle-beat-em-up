# Z-God concepts v1

Three transparent character concepts generated with the built-in image generation tool, using X God's card and Barrett's idle artwork as style references.

- A — Side-bow adventurer: star sweater, pleated skirt.
- B — Pigtail powerhouse: heart sweater, twin bows.
- C — Ponytail heroine: Z sweater, layered skirt.

Awaiting the user's design selection before animation sheets or gameplay integration. Intended gameplay: shorter than the other heroes, invincible, and able to defeat any enemy in one hit. Z-God is X God's six-year-old sister.

Exact prompts, references, and original generated paths are recorded in prompts.json. Generated originals are preserved.
